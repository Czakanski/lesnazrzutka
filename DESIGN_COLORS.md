# 🎨 Kolorowy Design - Lesna zrzutka

## ✨ Co zostało dodane

Projekt został udekorowany kolorami dla lepszego wyglądu i doświadczenia użytkownika.

### 📝 Kolory używane

```
🟣 Primary (Główny):      #667eea - Fioletowy/Niebieski
🟤 Secondary:             #764ba2 - Fioletowy ciemny
🟢 Success:               #4caf50 - Zielony
🔴 Error:                 #ff6b6b - Czerwony
🟡 Warning:               #ffc107 - Pomarańczowy
🔵 Info:                  #2196f3 - Niebieski
⚪ Light Background:      #f8f9ff - Jasnofioletowy
```

## 📝 Customization

Aby zmienić kolory, edytuj `:root` variables w `styles.css`:

```css
:root {
    --primary-color: #667eea;      /* ← zmień tutaj */
    --secondary-color: #764ba2;    /* ← zmień tutaj */
    --success-color: #4caf50;      /* ← zmień tutaj */
    /* itd... */
}
```
